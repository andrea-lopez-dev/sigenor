Excelente pregunta. Vamos a **integrar todos los módulos en Laravel** de forma clara, práctica y funcional. A continuación te explico **cómo se conectan entre sí**:

---

## 🔧 1. **Base de datos**

Laravel usa Eloquent ORM para conectarse a tu base de datos.
Esto se configura en el archivo `.env`:

```dotenv
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=sigenor
DB_USERNAME=root
DB_PASSWORD=
```

Este `.env` se usa automáticamente cuando tú haces llamadas a Eloquent como:

```php
Usuario::where('id_usuario', $id)->first();
```

---

## 👤 2. **Modelo de usuario personalizado**

Creamos el modelo `Usuario` para que Laravel sepa qué tabla usar en lugar de `users`:

```php
// app/Models/Usuario.php
use Illuminate\Foundation\Auth\User as Authenticatable;

class Usuario extends Authenticatable
{
    protected $table = 'usuarios';
    protected $primaryKey = 'id_usuario';
    public $timestamps = false;

    protected $fillable = ['name', 'foto', 'rol'];
}
```

> ⚠️ Esto es fundamental si tu tabla de usuarios se llama `usuarios` y no `users`.

---

## 🧩 3. **Configuración del autenticador**

Laravel usa guards para autenticar. Necesitamos decirle que use nuestro modelo:

```php
// config/auth.php

'providers' => [
    'users' => [
        'driver' => 'eloquent',
        'model' => App\Models\Usuario::class,
    ],
],
```

Esto hace que cuando tú inicies sesión, Laravel use la tabla `usuarios`.

---

## 🔐 4. **Autenticación de sesión**

Si instalaste Laravel Breeze o Laravel UI (recomendado), ya puedes usar:

```php
Auth::user() // Devuelve el usuario logueado
```

Y proteger rutas así:

```php
Route::middleware('auth')->get('/dashboard', function () {
    // Usuario autenticado
});
```

Esto reemplaza todo este bloque antiguo:

```php
session_start();
if (!isset($_SESSION['id_usuario'])) {
    header("Location: ../home.php");
}
```

Laravel maneja sesiones automáticamente.

---

## 🧑‍🎓 5. **Verificación de rol y carga de imagen**

En el controlador o ruta puedes acceder al usuario y su rol:

```php
$usuario = Auth::user();

if ($usuario->rol != 1) {
    return redirect('/home');
}

$foto = $usuario->foto ?? asset('Assets/img/subidas/user.jpg');
```

---

## 🌐 6. **Rutas**

En `routes/web.php` defines:

```php
Route::middleware('auth')->get('/dashboard', function () {
    $usuario = Auth::user();
    if (!$usuario || $usuario->rol != 1) return redirect('/home');

    $foto_perfil = $usuario->foto ?? asset('Assets/img/subidas/user.jpg');
    return view('dashboard', compact('usuario', 'foto_perfil'));
});
```

Esto reemplaza la lógica antigua PHP `if ($_SESSION['rol'] != 1)`.

---

## 🧾 7. **Vista Blade (`resources/views/dashboard.blade.php`)**

Aquí se carga tu animación + contenido con datos del usuario:

```blade
<h2>Bienvenido, {{ $usuario->name }}</h2>
<img src="{{ asset($foto_perfil) }}" alt="Foto de perfil">
```

La animación con CSS/JS se activa antes de mostrar `#contenido`.

---

## 🔁 RESUMEN VISUAL DE INTEGRACIÓN

```text
.env ➝ Configura DB
⬇
Usuario.php ➝ Define el modelo de usuarios
⬇
config/auth.php ➝ Le dice a Laravel que use el modelo Usuario
⬇
Middleware auth ➝ Protege rutas
⬇
web.php ➝ Define la lógica de acceso
⬇
Blade ➝ Muestra animación + datos del usuario
```

Instalar Laravel desde **Visual Studio Code (VS Code)** es muy fácil, **siempre que tengas configurado tu entorno de desarrollo**. A continuación te explico paso a paso cómo hacerlo desde cero:

---

## ✅ REQUISITOS PREVIOS

Asegúrate de tener instalados en tu sistema:

| Herramienta        | Descripción                   | Cómo verificar                              |
| ------------------ | ----------------------------- | ------------------------------------------- |
| PHP ≥ 8.1          | Motor de Laravel              | `php -v` en terminal                        |
| Composer           | Gestor de dependencias de PHP | `composer -v`                               |
| MySQL o MariaDB    | Base de datos                 | (verifica que esté activo)                  |
| VS Code            | Editor de código              | [Descargar](https://code.visualstudio.com/) |
| Terminal integrada | Extensión incluida en VS Code | Usa Ctrl + \` (tilde invertida)             |

---

## 🧰 PASO 1: ABRE VS CODE Y UNA CARPETA BASE

1. Abre **Visual Studio Code**.
2. Haz clic en **File → Open Folder** y elige una carpeta vacía donde instalarás Laravel (por ejemplo: `C:\xampp\htdocs\sigenor`).

---

## 💻 PASO 2: ABRE LA TERMINAL DE VS CODE

Pulsa:

```plaintext
Ctrl + `
```

Eso abre la terminal integrada.

---

## 📦 PASO 3: INSTALA LARAVEL EN LA CARPETA

En la terminal de VS Code, escribe:

```bash
composer create-project laravel/laravel .
```

> El punto (`.`) indica que quieres instalar Laravel **en la carpeta actual**.

---

## ⚙️ PASO 4: CONFIGURA EL ARCHIVO `.env`

1. Laravel crea un archivo `.env.example`. VS Code lo muestra como `.env`.
2. Ábrelo y configura la conexión a tu base de datos:

```dotenv
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=sigenor
DB_USERNAME=root
DB_PASSWORD=
```

> Si usas XAMPP o Laragon, esos son los valores por defecto.

---

## ▶️ PASO 5: INICIA EL SERVIDOR LARAVEL

En la misma terminal de VS Code:

```bash
php artisan serve
```

Abre tu navegador y visita:

👉 [http://localhost:8000](http://localhost:8000)

Verás la página de bienvenida de Laravel 🎉

---

## 📁 ESTRUCTURA DE ARCHIVOS QUE DEBES CONOCER

| Carpeta                | Función                                          |
| ---------------------- | ------------------------------------------------ |
| `app/Models`           | Tus modelos (como `Usuario.php`)                 |
| `routes/web.php`       | Aquí defines tus rutas web                       |
| `resources/views`      | Aquí van tus vistas (con extensión `.blade.php`) |
| `app/Http/Controllers` | Tus controladores PHP                            |
| `public/Assets`        | Aquí colocas tus CSS, JS e imágenes              |

---

## 🧪 ¿CÓMO PROBARLO?

Crea una ruta simple en `routes/web.php`:

```php
Route::get('/prueba', function () {
    return 'Laravel funciona en VS Code 🚀';
});
```

Luego visita: [http://localhost:8000/prueba](http://localhost:8000/prueba)

---

## ❓¿Y si me da error?

Aquí algunos tips comunes:

| Error                        | Solución                                                         |
| ---------------------------- | ---------------------------------------------------------------- |
| `php` no reconocido          | Agrega PHP al PATH de tu sistema                                 |
| `composer` no reconocido     | Instala Composer y reinicia VS Code                              |
| `403 Forbidden` en navegador | Asegúrate de usar `php artisan serve`, no solo abrir el archivo  |
| `.env` no cargado            | Copia `.env.example` a `.env` y corre `php artisan config:cache` |
